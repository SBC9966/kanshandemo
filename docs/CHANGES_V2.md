# v1 → v2.0

## 内容
新增36条来源、15站与24问答的来源映射；24知乎入口和12公开参考页分别标注访问范围。完善哲学家差异、自由与处境、Agent工具边界、因果与概率假设。新增资料馆、对读、来源收藏、知识向导与理解图谱。

## 交互
三套地图几何与场景重建，原插画转为氛围层。新增15种主题操作，步行/台阶/桥/船/轨道/升降/缆索区别呈现。实验有效性与理解确认共同解锁。

## 工程
独立activity reducer、纯函数检索、引用审计、完成快照、v1记录兼容、滑杆实时更新保焦点、知识JSON导出、本地知识API、模型来源白名单。修复 malformed 记录数组可能造成恢复异常、重访重置可能丢已完成进度、滑杆更新可能重建控件的问题。

## 仍保留
离线独立HTML，零运行时依赖，三步问路、生成过渡、地图缩放拖动、所有阅读内容、笔记、收藏、山顶导出、偏好、环境音主动开启、备份恢复和可选模型适配。

## 没有伪装完成
没有授权知乎全文、账号画像、通用实时问答、通用实验生成、生产级Agent安全系统或线上公共部署。模型只做可选扩展，三座精细预设不依赖模型服务。

补充：知识检索加入词频权重与精确问句优先，避免“Agent与工作流区别”被泛化的Agent定义抢占。增加24条问句自匹配与典型意图回归检查。
