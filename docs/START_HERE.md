# 看山不是山 v2.0 · 知识考察版

这次升级不是多加几个页面：建立了真实来源的本地知识库，并重做三座山的地形、路线、交通与十五个营地操作。

## 打开

下载独立HTML到电脑，用Chrome或Edge打开；不要在聊天附件预览器中运行。或者解压完整工程，打开 `shan-demo-v2/index.html`。所有运行素材内嵌，不需要网络、账号或API Key。

做长期开发推荐安装Node.js20.11+，在工程目录运行：

```bash
node scripts/build.mjs
node server/index.mjs
```

然后访问 `http://localhost:8787`。没有第三方运行时依赖，无需npm install。Windows可双击START_SERVER.bat。

## 最值得先体验

首页切换三种地图，查看它们的几何、建筑和交通差异；进入资料馆，搜索“加缪”或“工作流”，打开访问范围、来源与所属营地，选择两项对读。

接着从任意主题开始，完成三步问路。每站需要先操作实验，再做理解确认；标题可预览，但后续内容按前置解锁。三山进度独立，可以随时返回首页开启另一座。

存在主义：行囊分类、时间线、思想问题配对、双视角栈道、个人寄语。AI Agent：回路编排、任务分流、真实本地检索与引用校验、权限闸门、三例验收。独立思考：陈述分类、样本揭示、因果图、证据比较、贝叶斯更新。

完成时观察人物沿对应路径步行、过桥、乘船、搭升降台或缆车。减少动画模式会直接到达，但不跳过理解条件、不丢进度。重访并重新操作实验也不会抹掉此前完成的记录。

## 资料与AI范围

知识库有36条资料：24个真实知乎问题/专栏入口，12个公开学术或官方参考页；组织成15营地、24策展问答、30概念、4条跨主题联系。

本次无法读取知乎完整正文，24条均标记“仅检索摘要”，不冒充读过全文。公开参考只表示读取了相关段落，不代表整篇逐句核验。所有讲解和实验为本项目组织，没有虚构知乎作者、点赞或用户画像。原站可能需要登录。

知识向导是真正的本地关键词检索，不是通用大模型或实时知乎搜索；没有匹配会说明不足。Agent实验里的工具确实调用本地函数，但不联网、不发邮件。统计与天气数字为明确标出的教学假设，不是真实统计结论。

可选模型接口在工程中，需要自己的服务端密钥。新主题可以生成通用五层阅读材料，但不会自动产生与三座预设同等精细的新实验或新地形。实际模型账户未测试，不附带密钥。

## 保存与导出

本地自动保存进度、笔记、实验参数与收藏。设置中能导出/导入JSON备份；考察手记为Markdown，山顶卡为SVG。兼容v1的旧学习记录。文件模式存储受浏览器设置影响，跨设备请使用备份；私人寄语可能包含在导出中，分享前自行检查。

## 包含的开发文件

完整源码、构建脚本、独立HTML、24个已有水墨素材、三套实时SVG场景、知识库JSON、15个实验、来源核查表、可复用开发提示词、演示脚本、测试与实机截图。具体看README与docs目录。

`docs/BUILD_PROMPT_V2.md`：公开开发任务提示词和验收标准。
`docs/RESEARCH_LOG.md`：检索方向、资料使用与取舍。
`docs/SOURCEBOOK.md`：36条来源逐条登记与访问边界。
`docs/INTERACTIONS.md`：十五站及解锁逻辑。
`docs/TEST_REPORT.md`：67项Node测试、48个浏览器场景检查及环境限制。

浏览器自动化通过set_content加载实际网页，并使用仅限测试的存储适配器；HTTP服务另测。没有把它说成所有浏览器原生file存储、手机实机或真实模型服务验证。尚未发布公共在线地址。
