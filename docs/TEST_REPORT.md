## 实际检查了什么

知识库：24条知乎资料全部是 `index-only`；所有营地都有知乎讨论入口及已读公开参考；36条资料都被使用。问题原句能命中自己的策展答案，典型“工作流区别”意图不会被泛化定义抢占，未知问题返回无足够匹配。URL与HTML安全处理、畸形记录恢复均有检查。

实验：十五个空状态均不能通过；真实状态更新后可以通过并持久化。只完成选择题、只完成实验或跳过前置都不能解锁。样本数与贝叶斯数值由公式校验。Agent起草前必须检索；外部写入与步数限制由函数阻止；模型引用限制在实际提供的本地来源ID中。

界面：资料馆搜索、筛选、收藏、两条对读、来源范围和原址链接。主流程实际操作拖放、排序、配对、分视角、填写寄语、工具步骤、权限与测试、滑杆与图表，再做理解确认。每种路段取到至少两次不同的人物变换值，并完成下一站，三山最终5/5。

状态：笔记跨页保存，来源收藏，完整记录序列化恢复，个人寄语出现在山顶，导出 Markdown / SVG / JSON；真正选择备份文件并确认导入；错误JSON不覆盖已有数据。旧版v1进度兼容；已验证完成的营地重置当前实验仍保留历史进度。

体验：地图zoom/pan/reset、晨光/暮色、减少动画、滑杆连续键盘输入保留焦点、Escape关闭弹窗、取消破坏操作、取消生成后计时器不会偷偷导航、手机无横向溢出。环境音未以真实扬声器做听感验证。

## 测试环境的明确限制

当前沙盒禁止浏览器直接导航 localhost，因此浏览器测试使用 `page.set_content` 装载真实构建产物，并注入**仅在测试中的 Storage 适配器**。这样能测试真实 DOM 事件、状态序列化、文件导入导出、SVG位移和页面布局；不能据此声称已验证所有浏览器对 `file://` 的原生持久化行为，也不能声称浏览器端的 localhost 网络导航通过。

HTTP服务则由Node使用真实本机HTTP请求独立验证，包括状态、静态资源、资料过滤、本地问答、错误请求、HEAD、禁止私密文件以及未配置模型时不伪造成功。模型上游由本机测试服务器模拟，覆盖合法结构、非法结构、服务失败、跨域拒绝、来源白名单；**没有使用真实模型账户或真实知乎登录态**。

自动化运行期间没有发现未捕获的浏览器JavaScript错误。截图位于 `tests/v2-screenshots/`，是实际网页而非AI效果图。全页截图里的固定底部操作条会出现在截图对应的当前视口位置，这是浏览器固定定位的捕获方式，不表示它随文章排版占据中间位置。

## 本次定位并修复

滑杆更新导致焦点丢失 → 改为只更新数值与图形；重访重置抹去历史完成 → 独立完成快照；畸形活动数组恢复异常 → 白名单清洗；泛化词抢占更具体问题 → 词频权重与精确匹配；新手引导旧文案只要求答题 → 明确实验与理解双条件。

测试脚本的原生拖放需要先使源与目标同时可见，再使用真实鼠标事件；遵守浏览器滚动和固定导航布局，不通过直接写入完成态代替操作。所有测试适配仅在tests目录，不打入HTML。

## 复现

```bash
npm run build
npm run audit
npm test
python tests/v2-browser.py
python tests/v2-extra-browser.py
```

浏览器另需Python Playwright与Chromium，设置 `CHROMIUM_PATH` 可覆盖默认Linux路径。以部署目标环境再核对原生存储、音频、触摸手感与真实模型。网页不使用外部运行时依赖，普通用户无需安装测试工具。
