# 方案一路演 · 三分钟操作稿

## 演示前
用桌面 Chrome/Edge，浏览器缩放100%，显示宽度建议1440左右。使用本地服务器避免附件预览器限制。新窗口或设置重置可从零演示；需要展示第三站/第五站时，提前亲自完成前置并保存备份，明确那是先前的学习记录，不宣称第一次使用已自动解锁。不要临场伪造跳级。

## 0:00—0:30 先让差别发生
首页展示：“信息可以推荐给你，但理解需要一条可走的路。”切换三个主题预览：同样的五层组织，在存在主义是山径，在Agent是工坊，在独立思考是峡谷。展示真实地图几何变化，不放预录视频。

## 0:30—1:00 让内容可追溯
打开资料馆，筛选知乎，搜索“加缪”，打开一张卡的来源范围，再选两条资料对读。“不是把帖子换成山的形状；我们同时保留问题、出处、可读取的范围及它对应的知识位置。”说明知乎24条为真实索引入口，12条公开资料提供交叉参考，不冒充读到了知乎全文。

## 1:00—1:40 演示从操作到理解
使用已到第二站的独立思考旅程，拖动样本滑杆。最初18/20成功，逐渐纳入80个不可见样本后变为30/100。解释：“不是多读一篇提醒注意偏差的文章，而是亲手看见分母改变。”所有数字标注为教学假设。提交实验与理解确认，小人沿该地形下一段路线前进。

## 1:40—2:20 证明工具真的做了事
进入已到第三站的Agent工坊。先尝试没有检索就形成草稿，看到阻止反馈；随后运行检索、查看证据、草稿、引用校验，展示实际命中的source ID和事件日志。说明本地检索是真执行，而不是把生成文字说成联网结果。完成后看缆车路段。

## 2:20—2:45 个性不是装扮
展示存在主义第五站的自己寄语，或第一站的处境/行动行囊。它不判断你该选什么人生，而是鼓励说明限制、行动和修正条件。指出三山不是同一道题改标题。

## 2:45—3:00 留下可带走的理解
理解图谱中显示自己的学习记录及跨主题问题，导出考察手记。收束：“我们希望留下的不只是收藏，而是一个知道从哪里来、也知道如何修正的理解。”

## 新用户简短版
首页 → 存在主义 → 三步问路 → 第一站行囊 → 理解确认 → 沿溪上行 → 下一站。剩下的主题用首页预览和资料馆说明，不假装90秒能完成十五站。
