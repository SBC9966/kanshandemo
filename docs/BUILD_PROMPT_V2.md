# v2 实施任务提示词

以下是可交给下一位开发者或 AI 的公开任务书与验收标准，不是私有思维记录。

## 角色与目标
你负责升级“看山不是山”方案一的真实交互网页。保留已有水墨、纸张、旅行者和轻量空间感，让知识内容、场景、操作及前置解锁互相对应。交付可离线打开的完整 HTML、可维护源码、带出处的知识库及测试记录。不是生成一张更漂亮的页面图，也不是只写 PRD。

## 必须遵守的产品范围
仅做知识登山，不增加 Agent 社交房间、热梗海滩、付费装扮、账号系统或未接通的“推荐大数据”。完成存在主义、AI Agent、独立思考三座山，每山五营地。标题可预览，阅读与实验按前置顺序开放。

## 资料工作
1. 按概念、历史、机制、分歧、应用搜索知乎问题与专栏，记录真实地址、可见题目、作者可见性及读取范围。
2. 无法读全文时明确标成索引摘要，不绕过登录，不推断全部回答的观点，不编造高赞数。
3. 每个营地另配公开学术、作者或官方参考页。原创导读与来源内容分离。
4. 建立 source → camp → concept → question 关联，资料可搜索、筛选、收藏、对读、跳回营地。

## 场景与操作
三座山不可共用一张图换色：必须有不同 SVG 地形、站点坐标、路径、建筑与交通。存在主义是溪谷、石阶与双径桥；Agent 是回路、轨道、升降台与缆车；独立思考是码头、样本湖、因果河、天平与灯塔。小人按真实 SVG 路径取点移动。

十五站不能复用一种选择题：实现拖放分类、排序、问题配对、双视角、个人寄语、步骤编排、工具选择、真实本地检索、权限闸门、确定性测试、事实辨别、样本揭示、分组因果图、证据比较与概率更新。变化必须来自用户操作和代码计算。外部发送、联网能力及工具返回不能伪装。

## 解锁与状态
实验操作有效 + 理解确认正确 + 已完成前置，三条件共同解锁。哲学价值选择不判对错，只检查是否区分概念与说明处境。完成先保存再动画，跳过动画不丢进度。重访、清空当前实验不抹去已验证的历史完成记录。兼容 v1 本地学习记录。

## 工程要求
保持零运行时依赖，原生 JS/HTML/CSS/SVG，源码模块化，构建成自包含 HTML。API 密钥仅在服务端。所有文字、按钮、锁、路径、数字与实验控件是实时 DOM/SVG，不嵌在插画内。减少动画、键盘操作、触摸替代操作、手机排版、空态、无资料结果、取消、重试、数据导出都要检查。

## 验收
- 36 条真实来源，每条有范围；15 站和 24 问答均有稳定引用。
- 实际完成三山十五站，不仅替换 seed；额外检查问答单独通过不能解锁。
- 比较三条世界的几何、交通和动画位移。
- 样本比例与贝叶斯结果由公式计算；本地 Agent 必须产生检索与引用验证事件。
- 资料检索、收藏、对比、无匹配拒答、笔记与导出可用。
- 390 / 768 / 1024 / 1440 像素布局检查。
- 运行知识审计、领域测试、实际 HTTP 测试与浏览器操作测试。说明环境限制，不能把模拟上游叫成已测试真实 AI。

## 交付组织
README → 三分钟演示脚本 → 来源核查表 → 15 个交互说明 → 代码 → 知识库 → 测试。修改文档与旧版本不一致的表述，避免演示承诺大于实际能力。
