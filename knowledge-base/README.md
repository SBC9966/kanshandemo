# 本地知识库说明

`knowledge-base.json` 是完整快照；其余 JSON 是拆分版，便于接入别的前端、数据库或检索服务。代码实际从 `src/data/*.mjs` 与 `src/knowledge-engine.mjs` 读取，修改导出的 JSON 不会自动改变网页。修改源码后运行 `node scripts/export-knowledge.mjs` 和 `node scripts/build.mjs`。

## 数量与来源
36 条资料（24 个知乎问题/专栏入口 + 12 个公开学术或官方参考页），15 个营地，24 条附来源的策展问答，30 个概念标签，4 条跨主题联系。

## 字段
`sources` 包含稳定 ID、真实地址、题目、发布方、可见作者、主题、标签、导读、检查日期、访问级别与范围。`index-only` 只能作为讨论入口，不能声称已读全文；`page-read` 表示读取了相关公开段落。`units.sourceIds`、`questions.sourceIds` 与各营地的 `sourceIds` 都关联稳定 ID。

个人笔记、浏览器进度、账户、密钥不在此库中。没有全文复制、虚构点赞数、原作者立场推断或实时推荐画像。教学实验的数据明确为假设，不是现实统计结果。

## 继续接入真实授权内容
新增数据时保留稳定来源 ID 和 `access` 字段，补充有权使用的片段、定位与获取日期，再增加校对后的问答及营地关联。不可通过覆盖 `access` 把只有搜索摘要的内容标记为全文。若接入第三方向量库，也保留当前无匹配拒答与来源范围提示。
