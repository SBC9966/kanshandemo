# 看山不是山 · v2.0 知识考察版

> 不止读到一个答案，亲手走进它的来路。

本版升级方案一：**真实来源知识库 + 三种矢量地形 + 十五个可操作的营地实验 + 双条件解锁**。没有增加 Agent 社交房间、海滩或账号系统。

## 立即运行

最简单：将文件保存到电脑，用 Chrome 或 Edge 打开根目录 `index.html`；`dist/index.html` 是同样的独立成品。全部插画、脚本、样式及资料元数据均已内嵌，不需要网络或购买 API。Windows 可双击 `OPEN_DEMO.bat`。聊天附件预览器可能禁止脚本，请下载后打开。

推荐用于持续开发的方式：安装 Node.js 20.11+，在项目目录运行：

```bash
node scripts/build.mjs
node server/index.mjs
```

浏览器打开 `http://localhost:8787`。无需 `npm install`，没有运行时第三方依赖。Windows 可运行 `START_SERVER.bat`；Mac / Linux 可运行 `sh start-server.sh`。服务器没有热更新，改源码后重新构建并刷新。完整地重导出知识库和网页可运行 `npm run build`。

## 先看哪几处

1. 首页点击“存在主义 / AI Agent / 独立思考”预览，三张图会改变地形、建筑与路线，不只是换颜色。
2. 进入“资料馆”，筛选知乎、输入“加缪”、打开来源详情，查看访问范围与营地关联；选两条资料对读。
3. 从首页选择一座山，完成三步问路。每站先操作实验，再做理解确认，之后才能前进。锁定的营地仍可预览题目。
4. 在“我的山途”继续另一个主题。各山进度独立，不必一口气完成一座后才能看另一座的第一站。
5. 完成后查看“理解图谱”，保存山顶卡片、资料与考察手记。

## 知识库不是假搜索

内置 **36 条资料**：24 个真实知乎问题/专栏入口和12个公开学术或官方参考页；关联15个营地、24条带引用的策展问答、30个概念与4条跨主题联系。

**重要边界：知乎页在本次环境无法读取完整正文。** 24条均标记 `index-only`：检索可见题目与部分摘要，原文可能需要登录，不冒充完整阅读。题目对应的每个回答可能观点不同，卡片不代表全站共识。12条其他参考页读取了相关段落，不意味着全文逐句核验。

本项目的导读、练习与问答是编辑组织，不是原作者全文/摘要转载；无虚构点赞、浏览数或画像。资料馆支持搜索、主题/来源筛选、收藏、双条对读、原站链接及营地跳转。“看过来源卡”也不等于“读过原文”。

“知识向导”用中文二元词与英文词做实际本地关键词匹配，并降低过于常见词的排序权重，并返回策展问答与真实 source ID。没有匹配就明确提示不足。它不是通用大模型、实时站内搜索或向量 RAG。Agent 第三站真实运行本地检索和引用 ID 校验，但不会访问网络、发送邮件或执行任意代码。样本、因果与概率实验均为标明假设的教学数据。

## 交互不是一张背景图

主地图由独立 SVG 地形、建筑、路线和 DOM 节点组成；24个已有水墨 WebP 素材用于氛围与角色。三山使用不同坐标和四段路径，人物与船/吊舱按 `getPointAtLength` 移动。进度保存先于动画；跳过或关闭动画仍正常完成。

每站必须同时满足“实验操作完成、理解确认通过、前置营地已完成”。个人价值取向不评分。已完成记录有验证快照，重访修改实验不会抹掉登顶。滑杆即时重算且保留键盘焦点；拖放有按钮替代操作。配套取消生成、失败重试、空态、来源不足、减少动画、手机排版、笔记与备份。

## 学习记录

记录仅保存到当前浏览器，包括各主题进度、实验参数、笔记、收藏及来源卡访问记录。延续 v1 的存储键，兼容旧版已完成记录。文件模式的存储取决于浏览器设置；稳定持久化建议使用本地服务器和相同地址。隐私/无痕模式退出可能清除数据。

设置中可导出/导入 JSON 备份，导入前提示确认；考察手记导出 Markdown；山顶卡片导出 SVG。实验记录里包含你的手写寄语，分享备份前注意自行检查。

## 可选模型服务

默认离线模式已经可以完成三座山。只有希望生成预设之外的新主题时才需要模型。复制 `.env.example` 为 `.env`，配置完整 Chat Completions 兼容接口地址、密钥和模型名，重启服务：

```dotenv
MODEL_API_URL=https://your-provider.example/v1/chat/completions
MODEL_API_KEY=your-private-key
MODEL_NAME=your-model-name
PORT=8787
```

服务端会给模型提供最多6条相关本地资料元数据，要求返回五层结构；每条引用只接受输入中已提供的 ID。未知来源不会被模型的“有链接”说法自动认可。生成内容标记“AI生成·未外部核验”；没有资料时不编造引用。

**新生成的主题只有通用五层阅读与理解确认，不会自动创造本版15个手工设计的主题实验和新地形。** 三个预设世界的精细操作属于人工策展内容。实际模型账户未调用；适配器成功/失败路径以本地模拟上游测试。不同服务对 `response_format` 的支持需自行验证。

密钥只在服务端读取，不写入 HTML；私人的笔记和浏览记录不发给模型。当前没有生产级鉴权、计费和多实例限流，部署公网前需要补齐。不包含已发布的公共网址。
